## 尚待驗證與限制

- **本次自由輸入版實體 OLED 尚未驗收。** 先前使用者回報的固定數值 Unicode 診斷 HEX 通過，僅沿用其硬體／驅動證據，不能代替本次字串編碼路徑驗收。
- 原官方 `makecode.microbit.org` 沒有被修改；本修正尚未合併至上游，不宣稱已修復所有 PXT 版本。
- 常用字庫範圍外、字串超寬、容量不足仍有限制；字庫不是完整 Unicode。錯誤及局部更新引擎保持既有設計。
- 本次驗證限定 micro:bit V2；V1 不支援此完整字庫。
- 不提供 OLED 畫面模擬。網頁編譯可能連線上游原生編譯服務；燒錄後顯示完全在裝置執行。
- 舊專案 GitHub 相依套件自動移轉至內建自由輸入版、所有第三方套件相容性、全離線首次編譯未完成。
- npm 發行包缺少完整文件來源，因此建置只打包編輯器、既有模擬器與快取，文件連至官方；沒有冒充官方網站。
- 網頁開發主控台仍有上游 region URL 及部分翻譯參數的非阻斷訊息；本次實際下載已成功，並未宣稱主控台完全沒有訊息。

## 最短實機驗收

1. 下載四行加 A/B 的測試 HEX 至 micro:bit V2，確認四行中文。
2. 按 A，第三行 25 變 26，其他行保持，目視確認沒有明顯全頁閃爍。
3. 按 B，第一行改成「歡迎來到學校」。
4. 在修正版編輯器把文字改成另一組常用字，重新下載，確認顯示相同。

四步取得使用者回報後，才能將本版標示為實機通過。後續優先改善舊專案移轉及提交上游最小修正，再評估全班教學穩定性。
